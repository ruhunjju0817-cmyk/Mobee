# MOBEE AGV → 앱 블루투스 패킷 규격

AGV(Arduino)가 HC-05/HC-06으로 앱에 보내는 상태 패킷 규칙입니다.
앱 코드(`lib/services/agv_packet_parser.dart`)가 실제로 이렇게 동작하며, 이 문서와 테스트(`test/packet_test.dart`)로 확인됩니다.

---

## 1. 전송 방식

| 항목 | 규칙 |
|---|---|
| 연결 | 클래식 블루투스 SPP (HC-05 / HC-06). 앱은 휴대폰에 **미리 페어링된** 모듈 이름으로 연결 |
| 인코딩 | ASCII (UTF-8) |
| 한 패킷 | **한 줄**. 끝에 `\n` 필수. `Serial.println()`의 `\r\n`도 됨 |
| 줄 길이 | 1024자 이하. 1024자가 넘도록 `\n`이 없으면 앱이 버퍼를 비움 |
| 전송 주기 | **2초 안에 한 번 이상** 보내야 함 (권장: 200ms마다, 5Hz). 2초 넘게 안 오면 앱에 "데이터 없음"이 뜸 → [6. 데이터 끊김](#6-데이터-끊김) |
| 보레이트 | 앱과는 상관없음. Arduino와 HC-05 사이 설정만 맞으면 됨 (HC-05 기본값 9600) |

## 2. 패킷 형식

```
Z=2;S=WARN;H=SIDE;F=40;L=-1;R=11;T=3.5;V=0.38
```

- `키=값` 쌍을 `;`로 구분합니다. **순서는 상관없습니다.**
- 키와 값 앞뒤의 공백은 무시합니다.
- 키(`Z`, `S`…)와 S·H 값은 **대소문자를 구분하지 않습니다** (`s=warn`도 됨).
- 숫자 소수점은 `.`을 씁니다 (`3.5`).
- **`S` 필드가 없는 줄은 패킷이 아닌 것으로 보고 버립니다.** 디버그 출력은 S만 빼면 앱에 영향이 없습니다.
- 모르는 키는 무시합니다.
- 잘못된 값이 와도 앱은 죽지 않고 해당 필드만 Unknown 또는 미사용으로 처리합니다.

## 3. 필드

| 키 | 의미 | 단위 | 허용 값 | 없거나 잘못된 값일 때 |
|---|---|---|---|---|
| `Z` | 현재 구역 (RFID) | – | 정수 `1` `2` `3` `4` | `0`, 5 이상, 음수, 소수(`2.0`), 문자 → **Unknown** (화면: `–`, "위치 확인 불가") |
| `S` | 주행 상태 (MCU 동작) | – | `NORMAL` `WARN` `DANGER` `BLOCK` `STOP` | 모르는 값, 빈 값 → **Unknown** 상태 / 필드 없음 → 패킷 버림 |
| `H` | 위험 요소 목록 | – | `FRONT` `SIDE` `COLLISION` `TILT` `LINE_LOST`, `,`로 구분. 없으면 `H=` 또는 생략 | 모르는 코드 → **알 수 없는 위험** 1건 (화면에 "H 값 확인 필요"). 빈 항목(`,,`)은 무시 |
| `F` | 정면 초음파 거리 | cm | 0 이상 실수 | 아래 [미사용 센서](#5-미사용-센서) |
| `L` | 좌측 거리 | cm | **현재 좌측 센서 미장착 → 항상 `-1`** | 〃 (앱 표시: 항상 "미사용") |
| `R` | 우측 ToF 거리 | cm | 0 이상 실수 | 〃 |
| `T` | IMU 기울기 크기 | deg (°) | **0 이상** 실수 (부호 없이 절댓값). **10° 초과 시 Arduino가 `S=STOP;H=TILT` 전송** → [4장](#4-충돌기울기-전송-규칙과-우선순위) | 〃 |

> **센서 구성:** 정면 초음파 1개(`F`) + 우측 ToF 1개(`R`). **좌측에는 센서가 없으므로 `L`은 항상 `L=-1`** 로 보내 주세요.
| `V` | 진동 | g | 0 이상 실수 | 〃 |

### S: 주행 상태

| 값 | 앱 표시 | 의미 |
|---|---|---|
| `NORMAL` | Normal / 정상 주행 (초록) | 정상 주행 |
| `WARN` | Warning / 주의 필요 (노랑) | 감속 등 주의 |
| `DANGER` | Danger / 위험 감지 (주황) | 위험 감지, 정지 직전 |
| `BLOCK` | Blocked / 경로 차단 (빨강) | 장애물로 경로 막힘 |
| `STOP` | Stopped / 정지 (회색) | 정지 (원인은 H로 전달) |
| 그 외 | Unknown / 알 수 없는 상태 코드 (회색) | 보내지 말 것 |

### H: 위험 요소

| 값 | 앱 표시 | 의미 |
|---|---|---|
| `FRONT` | 전방 장애물 | 정면 장애물 감지 |
| `SIDE` | 측면 사각지대 | 측면 근접 |
| `COLLISION` | 충돌 | 충돌 감지 (항상 빨강) |
| `TILT` | 기울어짐 | 기울기 이상 (항상 빨강) |
| `LINE_LOST` | 라인 이탈 | 라인트레이서가 라인을 놓침 |

여러 개를 동시에 보낼 수 있습니다: `H=FRONT,COLLISION`

## 4. 충돌·기울기 전송 규칙과 우선순위

**충돌과 기울기는 `H`로 보내고, `S`에는 그때 MCU가 실제로 하는 동작을 넣습니다.**
보통은 멈추므로 `S=STOP`입니다.

| 상황 | 보낼 값 |
|---|---|
| 충돌 감지 | `S=STOP;H=COLLISION` |
| 기울기 이상 (**T가 10° 초과**) | `S=STOP;H=TILT` |
| 라인 이탈 | `S=STOP;H=LINE_LOST` |
| 충돌 + 기울기 | `S=STOP;H=COLLISION,TILT` |

S는 "AGV가 무엇을 하고 있는지", H는 "왜 그런지"를 나타냅니다.

**기울기 기준:** Arduino는 `T`가 **10°를 넘으면** (`T > 10`) `S=STOP;H=TILT`를 보냅니다.
정확히 10°일 때는 아직 보내지 않습니다.
앱 센서 카드의 기울기 색도 같은 기준으로 10° 초과일 때 빨강이 됩니다.
앱의 **5° 경고(노랑)는 앱 화면 표시용**으로만 쓰며, Arduino는 5°에서 아무것도 하지 않아도 됩니다.
`COLLISION`이나 `TILT`라는 S 값은 없습니다 (보내면 Unknown).

앱은 S와 H를 합쳐서 **최우선 경보** 하나를 고르고, 위험 상태 카드에 "최우선 경보: 충돌"처럼 표시합니다.

| 순위 | 경보 | 판단 기준 |
|---|---|---|
| 1 | 충돌 | H에 `COLLISION` |
| 2 | 기울어짐 | H에 `TILT` |
| 3 | 경로 차단 | `S=BLOCK` |
| 4 | 위험 | `S=DANGER` |
| 5 | 주의 | `S=WARN` |
| 6 | 정상 | `S=NORMAL` |
| – | (없음) | `S=STOP` 또는 Unknown이고 H에 충돌·기울기가 없을 때 |

`FRONT`, `SIDE`, `LINE_LOST`는 우선순위를 바꾸지 않고 위험 요소 타일에만 표시됩니다.

## 5. 미사용 센서

센서가 없거나 고장이면 **`-1`을 보내거나 필드를 아예 빼세요.** 앱 센서 카드에 **"미사용"**으로 표시됩니다.

| 보낸 값 | 앱 처리 |
|---|---|
| `L=-1` | 미사용 |
| (필드 없음) | 미사용 |
| 음수 전부 (`-5` 등) | 미사용 |
| 숫자가 아님 (`abc`, `nan`, `inf`) | 미사용 |
| `0` | **0으로 표시** (미사용 아님) |

- **좌측 센서(`L`)는 미장착이므로 항상 `L=-1`** 을 보내세요.
- IMU가 빠지면 `T=-1;V=-1`을 보내세요.
- 이 규칙 때문에 **기울기 `T`는 부호 없는 크기(0 이상)** 로 보내야 합니다. 음수 기울기는 미사용으로 처리됩니다.

## 6. 데이터 끊김

블루투스가 연결된 상태에서 **2초 넘게 패킷이 오지 않으면** 앱이 "데이터 없음" 배너를 띄우고 대시보드를 흐리게 표시합니다.
연결 직후 첫 패킷이 2초 안에 오지 않을 때도 마찬가지입니다.
다음 패킷이 오면 자동으로 원래대로 돌아옵니다.
그러니 **값이 바뀌지 않아도 주기적으로 계속 보내야 합니다.**

## 7. 센서 임계값

앱은 아래 값으로 **센서 카드의 색만** 정합니다. S와 H는 다시 계산하지 않고 Arduino가 보낸 값을 그대로 씁니다.
펌웨어의 판단 기준과 같은 값이어야 하며, 앱 코드에서는 `lib/models/sensor_thresholds.dart` 한 곳에 모여 있습니다.

| 센서 | 정상 (초록) | 경고 (노랑) | 위험 (빨강) |
|---|---|---|---|
| 정면 초음파 `F` | 50cm 이상 | 20cm 이상 50cm 미만 (감속) | 20cm 미만 (정지) |
| 우측 ToF `R` | 15cm 이상 | 8cm 이상 15cm 미만 | 8cm 미만 |
| 기울기 `T` | 5° 미만 | 5° 이상 10° 이하 (**앱 화면 표시용**) | **10° 초과** (Arduino `TILT` 정지 기준) |
| 진동 `V` ※ | 0.5g 미만 | 0.5g 이상 1.0g 미만 | 1.0g 이상 |

※ 진동은 Arduino 기준이 아직 정해지지 않아 앱에서 임시로 정한 값입니다. 정해지면 알려주세요.

경계값은 대부분 **위 단계**에 속합니다. 예: `F=50`은 정상, `F=20`은 경고, `R=8`은 경고입니다.
**기울기만 예외로**, Arduino와 맞추기 위해 `T=10`은 경고이고 10을 넘어야 위험입니다.

## 8. 상태별 예시 패킷

그대로 복사해서 시리얼 모니터나 블루투스 터미널 앱으로 보내 테스트할 수 있습니다.

| 상황 | 패킷 |
|---|---|
| 정상 주행 | `Z=1;S=NORMAL;H=;F=150;L=-1;R=40;T=1.2;V=0.12` |
| 주의 (측면 근접, 감속) | `Z=2;S=WARN;H=SIDE;F=40;L=-1;R=11;T=3.5;V=0.38` |
| 위험 (정면 근접) | `Z=3;S=DANGER;H=FRONT;F=15;L=-1;R=25;T=2.0;V=0.60` |
| 경로 차단 | `Z=2;S=BLOCK;H=FRONT;F=6;L=-1;R=6;T=0.8;V=0.05` |
| 정지 (위험 없음, Zone 4) | `Z=4;S=STOP;H=;F=200;L=-1;R=60;T=0;V=0` |
| 충돌 | `Z=3;S=STOP;H=COLLISION;F=3;L=-1;R=20;T=1.0;V=1.80` |
| 기울어짐 | `Z=2;S=STOP;H=TILT;F=120;L=-1;R=30;T=14.0;V=0.40` |
| 라인 이탈 (RFID 미인식, IMU 없음) | `Z=0;S=STOP;H=LINE_LOST;F=150;L=-1;R=50;T=-1;V=-1` |

이 표는 `test/packet_test.dart`의 `packetDocExamples`와 같아야 합니다. 바꿀 때는 둘 다 고쳐 주세요.

## 9. Arduino 전송 예시

AVR Arduino의 `sprintf`는 `%f`를 지원하지 않으므로 `print`를 이어서 씁니다.

```cpp
// bt: HC-05와 연결된 Serial (예: SoftwareSerial bt(10, 11);)
void sendStatus(int zone, const char* state, const char* hazards,
                float front, float right, float tilt, float vib, bool imuOk) {
  bt.print("Z=");  bt.print(zone);
  bt.print(";S="); bt.print(state);      // "NORMAL" / "WARN" / "DANGER" / "BLOCK" / "STOP"
  bt.print(";H="); bt.print(hazards);    // "" 또는 "COLLISION,TILT" 등
  bt.print(";F="); bt.print(front, 1);
  bt.print(";L=-1");                     // 좌측 센서 미장착
  bt.print(";R="); bt.print(right, 1);   // 우측 ToF
  bt.print(";T="); bt.print(imuOk ? fabs(tilt) : -1, 1);   // 부호 없이
  bt.print(";V="); bt.print(imuOk ? vib : -1, 2);
  bt.print('\n');
}

// loop()에서 200ms마다 호출
```
